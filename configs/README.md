# Configuration guide

Paths are relative to the repository root.

| Folder | Purpose |
| --- | --- |
| `models/` | Model-size configurations |
| `runs/` | Base-run configurations and the production-run manifest template |
| `data/` | Corpus preparation and tokenizer comparison settings |
| `evaluation/` | Evaluation prompts and acceptance thresholds |
| `testing/` | Small overfit configurations |
| `specialist/` | Independent specialist settings |

`smoke.yaml` stays at this level as the standard regression fixture.
